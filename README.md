# ToDo Manager 📝

A simple and elegant **WPF ToDo application** built with **MVVM**, **Entity Framework Core**, and **Dependency Injection**.

## Features
- Add, delete, and manage tasks
- Task priorities (Low, Medium, High)
- SQLite database with EF Core
- Clean architecture with DI
- Simple and adaptive UI

## Tech Stack
- C# / .NET 10
- WPF + MVVM Toolkit
- EF Core + SQLite
- Microsoft.Extensions.Hosting
